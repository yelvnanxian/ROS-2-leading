WHY

机器人数据不是“打开就能看见”。

RViz 必须知道订阅哪个 Topic、用哪种 Display 解码，以及把数据变换到哪个 Fixed Frame。三者任何一个错误，画面都会空白或报错。

RVIZ STATUS GUIDE

DEBUG MATRIX / 02
GREEN / OK

数据与 TF 正常

Display 正在收到消息，并能变换到 Fixed Frame。

YELLOW / WARN

暂时没有新数据

检查发布频率、Topic 名称和仿真是否暂停。

RED / ERROR

类型或 TF 不可用

展开 Status 阅读完整报错，不要直接重启。
